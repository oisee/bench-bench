# Data

Generated by `bin/export.py` from `runs/*/result.json`, the review files and the harness transcripts. The
critic-screening files are generated by `bin/critic-screen.py`.

| file | one row per |
|---|---|
| `runs.csv` | agent run (task × executor × round) |
| `reviews.csv` | L1 jury review of a run (critics saw test results) |
| `findings.csv` | defect reported by a jury critic |
| `critics.csv` | jury critic, aggregated |
| `leaderboard.csv` | executor, aggregated over round-1 runs. **`mean_score` / `overall_rank` are biased:** the jury covered L1 only, so do not use them |
| `critic-screen.csv` / `.json` | blind screening review / per-critic summary |
| `critic-adjudication.json` | rejections of test-passing patches, checked against the upstream reference |
| `task-sources.json` | exact briefs, task setup, grading commands, repository and commit metadata |
| `l3-finalists.json` | the frozen L3 selection, with its rule and evidence |
| `l3-corrected-eligibility.json` | L3 eligibility recomputed after the L2a grader fix |
| `l2a-hidden-name-fix-audit.json` | before/after status for the 16 regraded L2a runs |

`round` 1 is the baseline protocol. `round` 2 is the two-critic build-loop pilot.

## Run metrics (runs.csv)
- `round`: experiment round from `meta.json` (defaults to 1 for historical runs).
  Set `BENCH_ROUND=2` when launching the planned second L1 series.
- `status`: hidden tests (`RESOLVED` = all FAIL_TO_PASS and PASS_TO_PASS pass). `stop`: `DONE` or `TIMEOUT`.
- `effective_resolved`: `status == RESOLVED` and no `jury_override` (a defect reproduced by hand that tests miss).
- `duration_s`: wall-clock of the agent session (limit per level in `matrix.yaml`).
- `llm_calls`: model responses (pi: assistant messages; claude: distinct message ids; codex: not reported → empty).
- `tool_calls`, `tools_by_name`: tool invocations from the transcript.
- `input_tokens` (incl. cached), `cached_input_tokens`, `output_tokens`, `reasoning_tokens`, `total_tokens` = input + output.
- `cost_api_usd`: list-price equivalent from `prices.json` (empty when the price is unknown);
  `cost_plan_usd`: share of a subscription by its quota unit (Alibaba: $50 / 90 000 calls × `llm_calls`).

## Scores
- Jury aggregates exclude self-reviews and failed reviews.
  `jury_correct_share` = mean(correct=1, uncertain=0.5, incorrect=0); `jury_quality_mean` = mean quality 1–5;
  `jury_penalty` = mean over critics of (P0 + 0.5·P1 + 0.1·P2).
- `score` (0–100) = 100·(0.6·effective_resolved + 0.25·(quality−1)/4 + 0.15·correct_share) − 10·penalty, clamped.
- `rank_in_task`: by score desc, then duration asc, within the same task,
  round and protocol.
- Pareto flags per task, round and protocol (not dominated: another run with ≥ score and ≤ X, strictly better in one):
  `pareto_quality_speed` (X = duration), `pareto_quality_tokens` (X = total tokens), `pareto_quality_cost` (X = cost_api_usd; empty when unknown).
- Winners per task: `best_quality`, `fastest_solved`, `fewest_tokens_solved`, `cheapest_solved`.
